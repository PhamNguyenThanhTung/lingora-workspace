# D0 protocol — authorized characterization only

Baseline: accepted Independent WP-00/G0 design review 2026-10-25. Codex runs isolated experiments and reviews actual output/state; no Antigravity delegation or D1/D2 harness edits. No product migrations/schema, live/unknown environment, reused credential/data, A1/A2/A3 or P2. Existing repository source and historical evidence are immutable inputs.

New private temp root holds two empty provider homes and two fresh Git projects with a config-only fixture. Each tuple is reserved locally before prepare. CLI is existing local pinned 2.121.0; no global fallback. Child environment is explicit (Node PATH, private HOME/SUPABASE_HOME, experimental stack); no inherited provider/PG/credential env. No default/all-stack destructive action. Named/full-ID targets must match D0 intents. Fixed ports mean one running native instance at a time.

Sequence: (1) version/help/empty-home registry; (2) prepared tuple, cross-home/root/branch/name/full-ID selection; (3) lost-response/zero-match and bounded process interruption; (4) real start/status, exact credential reacquisition, stop/destroy and identity-bound process observations; (5) negative/error output and final cleanup. Adapt order based on observed provider behavior. Capture each exact command/cwd/exit/stdout/stderr schema and sanitized streams, before/after state where relevant. Raw streams and generated credentials remain private; evidence suppresses env values and known secrets. Do not claim sanitized evidence is raw secret-bearing output.

D0 PASS requires usable observations for all six requested areas, pinned actual schemas (not guessed DTOs), same-intent reconciliation rules and exact stop/destroy evidence. Unknown outcomes remain unknown; no blind retry/new ID or cleanup of unknown roots. If mandatory observation is unavailable, stop dependent experiments, perform only safe owned cleanup, and report D0 BLOCKED with precise technical incompatibility. D0 PASS does not accept G0 or authorize D1/D2 implementation. Only then may Codex issue a formal D1/D2 spec; no automatic Anti dispatch.
