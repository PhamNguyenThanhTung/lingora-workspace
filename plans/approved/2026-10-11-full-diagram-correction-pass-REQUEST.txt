# 8. Lesson Activity phải thể hiện đúng ADR-036

Không hard-code số câu.

Dùng:

`N core exercises`

Nếu learner sai lần đầu:

`Sai`
→ formative feedback
→ item chuyển xuống cuối queue
→ tiếp tục các item khác
→ retry item đó đúng 1 lần.

Retry:

- đúng → contribution `0.5`;
- sai → contribution `0`.

Đúng lần đầu:
- contribution `1.0`.

Nếu có:
- `N` core items;
- `K` first-attempt errors;

performance denominator:

`N + K`.

Không dùng ví dụ 12/13 trong rule diagram.

Completion:
- không yêu cầu 100%;
- độc lập correctness;
- hoàn thành flow core hợp lệ là complete.

# 9. SRS Activity

Phải thể hiện full lifecycle:

Core vocabulary
→ auto-enroll sau lesson completion.

Optional vocabulary
→ learner chọn Add to Review.

Một logical card:
`Learner + Vocabulary`.

Schedule:

`1 → 3 → 7 → 14 → 30 ngày`

sau đó:
`30 ngày/lần`.

Card không biến mất.

Forgot:
→ reset về stage đầu.

Same-session reinforcement:
→ đưa lại cuối session tối đa một lần;
→ không double scheduling operation.

Không dùng:
Again / Hard / Good / Easy.
