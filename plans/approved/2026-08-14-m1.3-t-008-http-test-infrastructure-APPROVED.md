## Approved HTTP Matrix

| Actor / operation | Expected result |
|---|---|
| Anonymous read, upload and delete | Denied |
| Learner A upload/read/delete own `profiles/{learnerAId}/{uniqueFilename}` avatar | Allowed for approved MIME/size |
| Learner B read/delete learner A avatar | Denied |
| Learner upload to another learner path | Denied |
| Invalid avatar path, MIME type or size | Denied |
| Upload over an existing object name | Denied; replacement uses a new filename/version |
| Learner upload/delete vocabulary audio | Denied |
| ADMIN/service upload/delete approved vocabulary audio | Allowed according to the existing PA2 policy |
| Learner read published/reachable vocabulary audio | Allowed |
| Learner read draft/unreachable vocabulary audio | Denied |

Observed HTTP status/response class and before/after object state are required. A database-only result cannot mark an HTTP case PASS.
