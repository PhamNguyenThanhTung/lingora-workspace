That successor silently replaces the latest content with the old tab's payload. Reload the actual current draft into the form, preserving unsaved work separately if needed, or require an explicit informed choice to apply it; block saves during recovery and while a conflict remains unresolved. Test two different server/local payloads, rather than token-only replacement.

The real Admin page test checks only heading/breadcrumbs. The Teacher test makes *every* fetch return 404, so a wrong URL/method/body still passes; it is not a killed callback mutant. The correct baseline must pass and an actual noop/wrong-endpoint source mutation must fail.

No actor/target disable between auth and transaction, simultaneous assignment/save collision, missing/mismatched assignment episode, or preserved topic/skill/purpose/coverage fields is exercised. The draft rollback test throws on revision creation **before any write**, so it cannot prove rollback after insertion. The double serializes all transactions even if production locks are deleted. Add the required negative requests, controlled interleavings/operative-lock assertions, and failure after revision insert or assignment/history writes; assert the whole aggregate and prior revision bytes remain unchanged. Run meaningful A–F controls after these tests exist.

4. **P2 — Admin stale recovery repeatedly uses the same stale token.** `lingora-admin/src/components/LessonFormModal.tsx:195-196`, `lingora-admin/src/components/LessonAssignModal.tsx:182-183`, `lingora-admin/src/components/LessonsCatalog.tsx:124-139`. Provide a real current-data reconciliation/reload action with retained input and test stale edit and assignment recovery.

5. **P2 — Clearing a title locale reports success while retaining the old value.** `lingora-admin/src/components/LessonDraftEditor.tsx:118-120,162-164`; server merge at `src/server/lessons/index.ts:1721-1732`. The form then keeps its blank field instead of reconciling `updated.currentDraft`, creating false success until reload. Send explicit empty values for cleared editable locales and reconcile all form fields from the success DTO. Cover locale removal and server-normalized values.
