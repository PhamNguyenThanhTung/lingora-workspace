### Language API

Use REST: `GET/POST /api/languages`, `PATCH/DELETE /api/languages/[id]` (UUID). GET returns `{data: LanguageDto[]}` ordered by code; POST 201/PATCH 200 return `{data: LanguageDto}` with the complete authoritative record; DELETE returns 204. DTO has `id`, `code`, `names`, `isLearnable`, `isUiLocale`; no Account rows or BigInt serialization. Error envelope `{error:{code,message,fields?}}` uses stable safe codes and Vietnamese UI messages. All routes require ACTIVE ADMIN before accessing catalogue data.

- Strict Zod create body: `code`, `names:{vi,en?}`, `isLearnable`, `isUiLocale`. Code uses frozen regex `^[a-z0-9]{2,10}(-[a-z0-9]+)?$` **and total length 2–10**; reject uppercase/invalid codes. Trim names; vi is required 1–100 characters; en optional <=100, blank clears/removes its key. Booleans must be actual booleans, not coerced strings.
- PATCH accepts only the mutable form fields (`names`, both booleans), with no `code`, `id`, timestamps or arbitrary properties; reject attempts to change code server-side. Preserve untouched existing locale keys when merging vi/en, including removing en when cleared. No name uniqueness rule and no invented Language status/isActive field. Current schema's names are JSON; handle legacy unexpected JSON shapes without unsafe rendering or server crashes.
- P2002 code conflict → 409 `DUPLICATE_CODE` with code field error; P2003 delete restriction → 409 `LANGUAGE_IN_USE`; absent record/P2025 → 404. Malformed JSON/UUID/body → 400, unsupported content type → 415. Database/provider unavailable → 503; unexpected errors → safe 500. Never return raw Prisma/SQL/network errors. Rely on FK enforcement for deletion, including racing references; no pre-delete counts or guessed dependency claims.
- Apply same-origin checks to POST/PATCH/DELETE and login/logout (reject foreign/missing/null Origin against the request's trusted application origin); JSON mutation content type; no broad CORS. Parameterized Prisma queries only. React text rendering escapes all names, including delete-dialog text; no raw HTML. Input authorization/validation failures make no mutation.
